# Аудиопримеры

Примеры озвучки для README: MP3 файлы лежат в этой папке, а в README встроены видео плееры, загруженные на GitHub как вложения. GitHub не показывает плеер для MP3, поэтому каждый пример превращается в видео с заголовком и волной звука.

| Файл | Что это |
|---|---|
| `examples.json` | Список примеров: имя файла, заголовок видео, язык, голос и текст |
| `make_examples.py` | Синтезирует примеры кодом сервиса и собирает MP3 и видео |
| `*.mp3` | Готовые примеры, хранятся в репозитории |
| `video/` | Видео для загрузки на GitHub, в репозиторий не попадают |

## Что нужно

- Окружение для разработки из [README](../../README.md#development): Python, зависимости из `requirements.txt` и `.venv`.
- [FFmpeg] в `PATH`.
- Шрифты Segoe UI. На Windows они есть, на Linux и macOS передайте свои через `--title-font` и `--subtitle-font`, например DejaVu Sans Bold и DejaVu Sans.

Модели и словарь английских слов скачаются при первом запуске, как у сервиса.

## Добавить или изменить пример

1. Добавьте пример в `examples.json` или поправьте существующий:

   ```json
   {
     "name": "dates",
     "title": "Даты и время",
     "language": "ru",
     "voice": "xenia",
     "text": "Сегодня 15.11.2026. Встреча 1 января в 14:30, работаем с 9:00 до 18:00."
   }
   ```

   - `name` — имя файлов: `dates.mp3` и `video/dates.mp4`.
   - `title` — заголовок на видео, на языке примера.
   - `language` — `ru` или `uk`.
   - `voice` — голос, по умолчанию `xenia` для русского и `mykyta` для украинского.
   - `text` — текст как в README, он проходит ту же обработку, что и запрос к `/process`.

2. Соберите пример из корня репозитория:

   ```shell
   .venv/Scripts/python docs/audio/make_examples.py dates   # Linux и macOS: .venv/bin/python
   ```

   Без имён пересобираются все примеры. Синтез детерминированный, поэтому у примеров, текст и обработка которых не менялись, MP3 получается тем же самым и в `git status` не появляется.

3. Послушайте `docs/audio/<name>.mp3` и посмотрите `docs/audio/video/<name>.mp4`.

## Загрузить видео на GitHub

1. Откройте на GitHub редактирование README или поле комментария в любом issue.
2. Перетащите туда `docs/audio/video/<name>.mp4`. GitHub загрузит файл и вставит ссылку вида `https://github.com/user-attachments/assets/...`.
3. Скопируйте ссылку. Комментарий можно не отправлять, файл уже загружен.

## Вставить в README

Ссылка ставится отдельной строкой после текста примера, под ней подсказка про звук:

````markdown
```text
Сегодня 15.11.2026. Встреча 1 января в 14:30, работаем с 9:00 до 18:00.
```

https://github.com/user-attachments/assets/...

<sub>🔈 GitHub запускает видео без звука, включите его кнопкой динамика в плеере.</sub>
````

GitHub показывает такую ссылку как плеер. Закоммитьте `examples.json`, MP3 и README.

## Как выглядит видео

Все видео собраны с одними параметрами, чтобы на странице они смотрелись одинаково. При изменении стиля пересоберите все примеры.

- 1280×360, 30 кадров в секунду, H.264 и AAC 48 кГц моно.
- Фон `#0d1117` и волна `#58a6ff` в цветах тёмной темы GitHub.
- Заголовок Segoe UI Bold 48 px, подпись `Silero TTS Service · <голос>` Segoe UI 26 px цветом `#8b949e`.
- Волна строится фильтром FFmpeg `showwaves` в режиме `cline` с шкалой `sqrt`.

Примеры голосов `voice-*.mp3` записаны раньше и в `examples.json` не входят.

[FFmpeg]: https://ffmpeg.org/download.html
