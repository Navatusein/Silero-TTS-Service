# Silero TTS

Локальный синтез русской и украинской речи на моделях [Silero](https://github.com/snakers4/silero-models). Аддон работает без интернета (интернет нужен только для скачивания модели при первом запуске) и предоставляет API, совместимый с MaryTTS.

## Установка

1. Добавьте репозиторий `https://github.com/Navatusein/Silero-TTS-Service` в `Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории`.
2. Установите аддон **Silero TTS** и запустите его.
3. При первом запуске аддон скачает модель выбранного языка (около 150 МБ). Модель сохраняется в `/data/models` и не скачивается заново при обновлении аддона.

## Подключение к Home Assistant

Добавьте в `configuration.yaml`:

```yaml
tts:
  - platform: marytts
    host: localhost
    port: 9898
    codec: WAVE_FILE
    voice: xenia
```

Перезапустите Home Assistant и проверьте озвучку действием `tts.speak` или `tts.marytts_say`.

Если Home Assistant не подключается к `localhost`, укажите в `host` имя хоста аддона: оно показано на странице аддона в разделе «Информация».

## Настройки

| Настройка | Описание | По умолчанию |
|---|---|---|
| `language` | Язык синтеза: `ru`, `uk`, `multi` | `ru` |
| `number_of_threads` | Количество потоков процессора | `4` |
| `sample_rate` | Частота дискретизации: `8000`, `24000`, `48000` | `48000` |
| `sox_param` | Эффекты [SoX](https://linux.die.net/man/1/sox), например `reverb 50 50 10` | пусто |
| `ha_fix` | Пауза в конце фразы, чтобы Home Assistant не обрезал окончание | `false` |
| `voice_tts_errors` | Озвучивать ошибки вместо ответа `400` | `false` |

Голоса для каждого языка:

| Язык | Голоса |
|---|---|
| `ru` | `aidar` `baya` `kseniya` `xenia` `eugene` |
| `uk` | `mykyta` `random` |

После изменения языка перезапустите аддон и поменяйте `voice` в `configuration.yaml`.

## Возможности

- Числа читаются словами, включая дроби: «23.5» → «двадцать три целых пять десятых».
- Слова в теге `<d>` склоняются по числу: `21 <d>яблоко</d>` → «двадцать одно яблоко».
- Эмодзи и разметка Markdown удаляются, поэтому можно озвучивать ответы LLM ассистентов.
- Поддерживается SSML: паузы, скорость и высота речи.

Подробности в [README проекта](https://github.com/Navatusein/Silero-TTS-Service).
