# Changelog

## 3.0.1 — 2026-10-22

### Исправления

- Сервис не запускался на процессорах без набора инструкций x86-64-v2 (SSE4.2, POPCNT), например в виртуальных машинах Proxmox с типом CPU `kvm64`: ошибка `ImportError: cannot load module more than once per process`. numpy закреплён на версии 2.3.

## 3.0.0 — 2026-10-22

Закрыты два пункта из давнего списка планов: сервис ставится как аддон Home Assistant, а склонение для украинского языка работает.

### Несовместимые изменения

- Русский голос `random` удалён: его нет в модели `v5_1`. Если он указан в настройках Home Assistant или Rhasspy, выберите другой голос.
- Два числа через запятую без пробела читаются как дробь: `1,5` — «одна целая пять десятых». Перечисления из трёх и более чисел (`1,2,3`) и перечисления с пробелами (`1, 2`) читаются как раньше.
- Файлы моделей называются по ссылке на модель, например `v5_1_ru.pt`, поэтому при смене версии модель скачивается заново. Старые файлы `ru_model.pt`, `uk_model.pt` и `multi_model.pt` больше не используются, их можно удалить.
- Python 3.14, Pydantic 2 и pymorphy3 вместо pymorphy2. Влияет только на запуск без Docker.

### Новое

- Установка как аддон Home Assistant.
- Образы для `amd64` и `aarch64`, публикация в Docker Hub и GitHub Container Registry.
- Модели Silero `v5_1` для русского и `v4` для украинского языка. Голоса звучат иначе, чем в предыдущей версии.
- Удаление эмодзи и разметки Markdown перед синтезом.
- Настройка `voice_tts_errors` для озвучивания ошибок.
- Настройка `models_directory` для папки с моделями.
- Аудио примеры голосов и обработки текста в репозитории.

### Исправления

- Параметры запроса `/process` не зависят от регистра, а при отсутствии параметра возвращается `400` вместо `500` ([#29](https://github.com/Navatusein/Silero-TTS-Service/issues/29)).
- Ответ `400` на ошибку `/process` содержит описание ошибки вместо пустого тела.
- Дроби читаются и с точкой, и с запятой, для украинского языка нормативно: «три цілих п'ять десятих».
- Исправлено склонение чисел и прилагательных в теге `<d>`, в том числе для украинского языка.
- Ошибки SoX больше не приводят к ответу `500`, а частично записанный файл не попадает в кеш.
- `/clear_cache` больше не возвращает `400`, если кеш ещё пуст после запуска.

## 1.0.0 — 2023-01-07

Первый релиз.

- HTTP API, совместимый с MaryTTS: `/process`, `/voices`, `/settings`, `/clear_cache`. Работает с Home Assistant и Rhasspy.
- Модели Silero `v3_1` для русского и `v3` для украинского языка.
- Числа читаются словами, слова в теге `<d>` склоняются по числу.
- Латиница читается транслитом.
- Поддержка SSML.
- Кеширование синтезированных фраз.
- Эффекты SoX через `SOX_PARAM` и пауза в конце фразы для Home Assistant через `HA_FIX`.
- Проверка настроек и автоматическое скачивание модели при запуске.
- Модель загружается один раз и используется для всех запросов, без утечки памяти.
